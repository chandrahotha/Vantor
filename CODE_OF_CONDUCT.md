# Code of Conduct - VANTOR

We pledge a harassment-free experience for everyone regardless of background or identity.

## Expected

Respectful, inclusive communication; constructive criticism; focus on technical merit and procurement user value.

## Unacceptable

Harassment, discrimination, trolling, personal attacks, publishing private info without consent.

## Enforcement

Violations may result in warning, temporary ban, or permanent removal. Report privately to
**digi.tracks@outlook.com**. All complaints reviewed confidentially.
