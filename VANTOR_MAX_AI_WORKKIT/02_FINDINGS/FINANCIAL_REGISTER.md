# Financial Integrity Register

The critical financial control chain is:

`PO approval -> budget reservation -> PO send -> receipt -> invoice -> cumulative match -> approval -> actual spend -> reporting`

VNT-001 through VNT-006 and VNT-027 are the main current risk cluster. The fix must be transactional and idempotent end-to-end.
