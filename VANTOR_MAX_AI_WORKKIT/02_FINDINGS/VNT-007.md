# VNT-007 — Webhook endpoint validation does not provide SSRF protection.

> **Source of truth:** Current VANTOR archive re-audit

## Classification

- **Severity:** High
- **Status:** Verified
- **Confidence:** High
- **Category:** Security

## Location

`backend/app/routers/integrations.py:46-83; backend/app/services/integration.py:81-125`

## Evidence

The endpoint accepts a URL if it starts with `https://` and the sender later calls `httpx.post(ep.url, ...)`. There is no DNS/IP policy, private/link-local/loopback/metadata address blocking, redirect validation, or egress allowlist.

## Impact

A tenant with integration-management access could cause the server to make requests to internal network targets.

## Required remediation

Resolve hostname before connect, reject private/loopback/link-local/multicast/reserved/metadata destinations, revalidate after redirects and DNS changes, and optionally allow an explicit tenant/domain allowlist. Use an isolated egress proxy in production.

## Required invariant / acceptance

The remediation must preserve tenant isolation, auditability, authorization correctness and deterministic behavior.

## Required tests

IPv4/IPv6 private ranges; localhost; 169.254.169.254; internal DNS; redirect to private address; DNS rebinding; allowed public HTTPS endpoint.
