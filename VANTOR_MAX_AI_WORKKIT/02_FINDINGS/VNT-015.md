# VNT-015 — Caller-supplied system prompt is concatenated into the model system instruction without a fixed policy boundary.

> **Source of truth:** Current VANTOR archive re-audit

## Classification

- **Severity:** Medium
- **Status:** Verified
- **Confidence:** High
- **Category:** AI security

## Location

`backend/app/routers/ai.py:159-172; backend/app/services/ai_gateway.py:247-271`

## Evidence

The request model permits a caller-supplied `system` string. The endpoint appends grounding data to that string and passes the result to the provider.

## Impact

A client with AI access can influence system-level instructions, potentially weakening grounding or safety constraints.

## Required remediation

Maintain an immutable server policy message. Treat user-provided instructions as user content, never as a replacement system prompt. Append grounding in a protected structured message and perform post-generation policy checks.

## Required invariant / acceptance

The remediation must preserve tenant isolation, auditability, authorization correctness and deterministic behavior.

## Required tests

Prompt that asks model to ignore grounding; tool evidence injection; role escalation in text; tenant data exfiltration attempt.
