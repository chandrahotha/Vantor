# VNT-037 — Copilot conversation turns reuse the IDs `you` and `ai`, causing duplicate React keys and incorrect updates across turns.

> **Source of truth:** Current VANTOR archive re-audit

## Classification

- **Severity:** High
- **Status:** Verified
- **Confidence:** High
- **Category:** Frontend correctness

## Location

`frontend/app/copilot/page.tsx:59-80,153-155`

## Evidence

Each send appends `{id: "you"}` and `{id: "ai"}` at line 69. Rendering uses `key={t.id}` at line 155. `patchTurn("ai", ...)` updates every turn whose id is `ai`, not just the active response.

## Impact

Multiple questions can create duplicate React keys and cause prior AI messages to be overwritten/updated together.

## Required remediation

Generate unique turn/message IDs, retain active AI turn id in the request closure, and patch only that turn. Add a test covering at least three sequential messages with streamed deltas.

## Required invariant / acceptance

The remediation must preserve tenant isolation, auditability, authorization correctness and deterministic behavior.

## Required tests

3 sequential prompts; interleaved errors; abort; retry; streaming evidence update; React strict mode.
