# VNT-039 — The current UI implementation is a minimal admin-console design, not a polished enterprise procurement workspace.

> **Source of truth:** Current VANTOR archive re-audit

## Classification

- **Severity:** Medium
- **Status:** Verified
- **Confidence:** High
- **Category:** Frontend UI quality

## Location

`frontend/app/globals.css:103-220; frontend/components/ui.tsx:14-130; many page files`

## Evidence

The application has ~101 inline `style={...}` occurrences across `frontend/app` and components. Shared UI primitives are limited to Badge, Empty, ErrorBox, Skeleton, StatCard, Pager, DataTable, and auth boot. The main shell is a fixed 248px sidebar plus a single max-width content column.

## Impact

Visual hierarchy, interaction consistency, composability and maintainability are insufficient for the requested Grade-5 product bar.

## Required remediation

Create a proper design system and component library: tokens, icon set, command palette, navigation states, drawers/modals, filters, bulk actions, charts, timelines, audit panels, contextual actions, keyboard navigation, responsive layouts, and visual regression baselines. Eliminate most page-local inline styles.

## Required invariant / acceptance

The remediation must preserve tenant isolation, auditability, authorization correctness and deterministic behavior.

## Required tests

Storybook/component tests; accessibility; visual snapshots at desktop/tablet/mobile; keyboard-only navigation.
