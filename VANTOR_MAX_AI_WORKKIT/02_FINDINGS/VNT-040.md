# VNT-040 — Production-critical frontend and concurrency scenarios are not verified by the current automated suite.

> **Source of truth:** Current VANTOR archive re-audit

## Classification

- **Severity:** High
- **Status:** Verified
- **Confidence:** High
- **Category:** Testing / QA

## Location

`backend/tests; frontend package and CI configuration`

## Evidence

The backend test suite contains extensive unit coverage, but the local PG infrastructure tests are skipped without PostgreSQL. There are no demonstrated concurrent transaction tests for budget/receipt/invoice/idempotency races. Frontend testing is Vitest-based; no browser E2E/visual/a11y suite is defined in the inspected CI workflow.

## Impact

The highest-risk classes of defects can survive while unit tests remain green.

## Required remediation

Add PostgreSQL integration as a required CI service, race/concurrency tests, browser E2E golden journeys, axe accessibility scans, visual regression, migration tests, security dynamic checks, and load tests. Make release gates explicit.

## Required invariant / acceptance

The remediation must preserve tenant isolation, auditability, authorization correctness and deterministic behavior.

## Required tests

All golden journeys; concurrent financial operations; a11y; visual diff; upgrade/migration test.
