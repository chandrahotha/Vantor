# Responsive and Mobile

Desktop 1440/1280, tablet 1024/768, mobile 390/430 must each have deliberate layouts. Never rely on horizontal scrolling for core actions alone. Tables transform into cards or prioritized columns on mobile. The command palette and work queue remain accessible.
