# Performance Budgets

Set measurable budgets: common reads p95 <= 500ms under target load; common writes p95 <= 750ms excluding intentional async operations; search p95 <= 800ms; page interactive readiness <= 2.5s on target device/network. Adjust with real measurements, not guesses.
