# VNT-013 — Document attachment references are only length-validated, not target-validated.

> **Source of truth:** Current VANTOR archive re-audit

## Classification

- **Severity:** Medium
- **Status:** Verified
- **Confidence:** High
- **Category:** Data integrity

## Location

`backend/app/routers/documents.py:86-104`

## Evidence

`resource` and `resource_id` are accepted as polymorphic strings. The route checks only maximum lengths and stores the values without verifying that the referenced resource exists in the tenant.

## Impact

Documents can become orphaned or point at non-existent business objects, weakening evidence chains.

## Required remediation

Replace free-form polymorphic pointers with typed attachment relations or an allowlisted resource registry with per-type existence/tenant checks. Add cascade/reassignment behavior for resource deletion.

## Required invariant / acceptance

The remediation must preserve tenant isolation, auditability, authorization correctness and deterministic behavior.

## Required tests

Unknown resource; cross-tenant resource id; deleted target; valid target of each supported type.
