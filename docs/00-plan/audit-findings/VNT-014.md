# VNT-014 — AI completion contract can return a factual-looking answer with an empty evidence list.

> **Source of truth:** Current VANTOR archive re-audit

## Classification

- **Severity:** Medium
- **Status:** Verified
- **Confidence:** High
- **Category:** AI safety

## Location

`backend/app/services/ai_gateway.py:247-271; backend/app/routers/ai.py:159-183; frontend/app/copilot/page.tsx:108-112`

## Evidence

`complete()` returns provider-generated text with `confidence: 0.55` and `evidence: []` at lines 270-271. The API then overwrites `result["evidence"]` with tool evidence at line 176. The UI claims every answer is evidence-cited.

## Impact

Users can receive ungrounded procurement advice under an evidence-cited product promise.

## Required remediation

Separate general-language answers from evidence-backed procurement decisions. When `AI_REQUIRE_EVIDENCE=true`, reject/label answers without evidence; expose evidence freshness, source type and exact record ids. Never use a fixed confidence value as a trust score.

## Required invariant / acceptance

The remediation must preserve tenant isolation, auditability, authorization correctness and deterministic behavior.

## Required tests

No-tools prompt; tools returning zero evidence; stale evidence; insufficient evidence; provider answer that contradicts evidence; UI status consistency.
