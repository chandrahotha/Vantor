# VNT-016 — Document semantic search stores embeddings as JSON and performs application-side cosine ranking after ILIKE filtering.

> **Source of truth:** Current VANTOR archive re-audit

## Classification

- **Severity:** Medium
- **Status:** Verified
- **Confidence:** High
- **Category:** Search / scalability

## Location

`backend/app/models/document.py:36-48; backend/app/routers/documents.py:224-255; backend/app/services/embeddings.py:91-110`

## Evidence

`DocumentChunk.embedding` is a JSON column. Search performs `ILIKE %query%`, limits to 50 rows, then calls `rank()` in application code.

## Impact

Search quality and scalability degrade as the corpus grows; only a small keyword candidate set can be semantically ranked.

## Required remediation

Use pgvector as a native vector column with appropriate HNSW/IVFFlat indexing, hybrid lexical/vector retrieval, metadata filters, tenant constraints, and bounded pagination. Reject vector dimension mismatches instead of truncating them.

## Required invariant / acceptance

The remediation must preserve tenant isolation, auditability, authorization correctness and deterministic behavior.

## Required tests

10k/100k/1M chunk benchmark; exact/semantic recall; dimension mismatch; tenant isolation; quarantined document exclusion.
