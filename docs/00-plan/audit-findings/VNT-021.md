# VNT-021 - Quote currency is not enforced to match the RFQ currency.

> **Source of truth:** Current VANTOR archive re-audit

## Classification

- **Severity:** Medium
- **Status:** Verified
- **Confidence:** High
- **Category:** Sourcing / currency

## Location

`backend/app/routers/sourcing.py:183-230; comparison at 235-257`

## Evidence

Quote creation defaults currency from the RFQ but accepts a different payload currency. Comparison sorts raw totals and reports RFQ currency separately without FX normalization.

## Impact

Comparing totals across currencies can produce invalid “cheapest” rankings and savings calculations.

## Required remediation

Either require exact currency equality or normalize to a documented base currency using an approved FX source, effective timestamp, and rounding policy. Never compare raw minor units from different currencies.

## Required invariant / acceptance

The remediation must preserve tenant isolation, auditability, authorization correctness and deterministic behavior.

## Required tests

Different currencies; same numeric totals; FX conversion; stale FX rate; missing FX rate; award blocked on mismatch.
