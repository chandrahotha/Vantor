# VNT-025 — Certification verification changes status without verifying the evidence itself or restricting verifier authority.

> **Source of truth:** Current VANTOR archive re-audit

## Classification

- **Severity:** Medium-High
- **Status:** Verified
- **Confidence:** High
- **Category:** Supplier governance

## Location

`backend/app/routers/suppliers.py:354-366`

## Evidence

`verify_cert()` requires only `_require_write(actor)` and then sets `row.status = "verified"` at line 362.

## Impact

A broad write role can attest that a certification is valid without a dedicated verifier role, expiry/evidence checks, or external validation.

## Required remediation

Require supplier-compliance permission, validate linked document readability/integrity and expiry, optionally integrate authoritative registries, require reason/notes, and audit verifier identity/source.

## Required invariant / acceptance

The remediation must preserve tenant isolation, auditability, authorization correctness and deterministic behavior.

## Required tests

Expired cert; missing document; quarantined document; wrong verifier role; re-verification after expiry.
