# VNT-031 — Content Security Policy is explicitly absent.

> **Source of truth:** Current VANTOR archive re-audit

## Classification

- **Severity:** Medium
- **Status:** Verified
- **Confidence:** High
- **Category:** Security headers

## Location

`backend/app/core/secheaders.py:1-23`

## Evidence

The module comments and code add several headers but do not emit a CSP header.

## Impact

XSS defenses remain weaker than a production enterprise application should have, particularly around future UI/plugin integrations.

## Required remediation

Deploy a strict CSP compatible with Next.js runtime, preferably nonce-based for any required inline script. Add `frame-ancestors`, `object-src none`, `base-uri self`, and reporting in controlled environments.

## Required invariant / acceptance

The remediation must preserve tenant isolation, auditability, authorization correctness and deterministic behavior.

## Required tests

CSP header presence; app loads with nonce; blocked inline script; blocked third-party origin; report-only migration.
