# VNT-038 - Provider options can say “needs your API key” but the Copilot page provides no key-entry flow.

> **Source of truth:** Current VANTOR archive re-audit

## Classification

- **Severity:** Medium
- **Status:** Verified
- **Confidence:** High
- **Category:** Frontend UX flow

## Location

`frontend/app/copilot/page.tsx:120-140`

## Evidence

The provider dropdown disables only unconfigured providers that do not need a key, and labels BYOK providers as “needs your API key”, but the page sends only `provider` and `prompt` to `aiStream()` and provides no field to capture a provider key.

## Impact

Users cannot complete a provider setup flow from the UI despite the UI explicitly exposing those providers.

## Required remediation

Provide a secure BYOK workflow that stores or passes the key using the intended transport without persisting it to browser storage, never logs it, and clearly shows provider readiness.

## Required invariant / acceptance

The remediation must preserve tenant isolation, auditability, authorization correctness and deterministic behavior.

## Required tests

Provider requiring key; configured server provider; invalid key; key cleared; no key reaches logs/storage.
