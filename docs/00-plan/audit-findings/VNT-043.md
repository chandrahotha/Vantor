# VNT-043 — Some summary values aggregate only under a single-currency assumption while the client has to suppress mixed-currency totals.

> **Source of truth:** Current VANTOR archive re-audit

## Classification

- **Severity:** Medium
- **Status:** Strong static finding
- **Confidence:** Medium
- **Category:** Financial aggregation

## Location

`backend/app/routers/spend.py; frontend/app/page.tsx:65-119`

## Evidence

The dashboard receives both scalar totals and a currency breakdown, then avoids showing scalar totals when `currencyCount > 1`. This signals that scalar aggregate fields are not inherently safe across mixed currencies.

## Impact

Other consumers could misuse scalar monetary fields and display invalid totals.

## Required remediation

Make cross-currency scalar totals impossible or rename fields explicitly (`singleCurrencyTotalMinor`) and require a currency key. Prefer map-of-currency aggregates in APIs.

## Required invariant / acceptance

The remediation must preserve tenant isolation, auditability, authorization correctness and deterministic behavior.

## Required tests

2+ currencies; missing currency; null currency; API contract schema forbids ambiguous aggregate.
