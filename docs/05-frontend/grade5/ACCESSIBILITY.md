# Accessibility

Target WCAG 2.2 AA. Keyboard-only operation for every workflow, visible focus, logical tab order, semantic landmarks, table headers, form labels/error descriptions, status announcements, reduced motion, color-independent status, adequate contrast, screen-reader-friendly live updates, and accessible charts via textual summaries.
