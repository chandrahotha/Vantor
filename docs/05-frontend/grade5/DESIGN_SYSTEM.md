# Design System

Define components before rebuilding pages. Required primitives/components: Button, IconButton, Link, Badge, StatusPill, Tooltip, Avatar, Breadcrumbs, Tabs, SegmentedControl, Input, NumberInput, MoneyInput, CurrencySelect, DateInput, DateRange, Search, FilterBar, DataTable, ColumnMenu, Pagination, Drawer, Modal, ConfirmDialog, Toast, Banner, InlineError, EmptyState, Skeleton, Progress, Timeline, MetricCard, Sparkline, ChartContainer, AuditTrail, EvidencePanel, ApprovalCard, ActionBar, CommandPalette, SidePanel, FileDropzone, DocumentViewer, Stepper, Wizard, FormSection, DiffViewer.

Every component must have keyboard/focus/ARIA behavior and visual states: default, hover, focus, active, disabled, loading, error, success.
