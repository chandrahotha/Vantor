# Synthetic Demo Standard

Each product gets a one-click or single-command demo seed using synthetic data. Demo mode must visibly declare that data is synthetic.

The demo should show one clean happy path, one difficult edge case and one security/approval boundary. It should be runnable offline or with the local mock services defined by the inherited Top-5 architecture.

Never use real supplier names, tax identifiers, bank accounts, contracts, invoices, addresses or confidential commercial values.
