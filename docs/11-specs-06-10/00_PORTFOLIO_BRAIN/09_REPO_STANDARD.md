# Repository Standard for Products 06–10

Every repository should contain:

`README.md`
`LICENSE` (choose/retain the approved project license)
`SECURITY.md`
`CONTRIBUTING.md`
`CHANGELOG.md`
`docs/BUILD_LOG.md`
`docs/API_CONTRACT.md`
`docs/RUNBOOK.md`
`docs/RELEASE_GATE.md`
`docs/adr/`
`app/` or `api/`
`engine/`
`ai/`
`worker/`
`web/`
`alembic/`
`tests/`
`seed/`
`integration/`
`docker-compose.yml`
`.env.example`
`.github/workflows/ci.yml`

The exact folders may vary only when an ADR records why.
