# Architecture Decisions

ADR-001: modular monolith for MVP; split services only where operationally justified.
ADR-002: deterministic domain services are the source of truth.
ADR-003: document content is untrusted.
ADR-004: AI output is untrusted.
ADR-005: evidence/provenance is first-class.
ADR-006: regional rules are effective-dated configuration.
ADR-007: no automatic irreversible award action.
ADR-008: public demos use synthetic data.
ADR-009: frontend never performs authorization decisions.
ADR-010: every material mutation is auditable.
