# UI/UX System

Enterprise procurement UI: clean, dense, evidence-led, neutral, table-centric, exception-first.

App shell:
top bar = workspace selector, global search, notifications, profile.
left nav = Dashboard, RFQs/Cases, Suppliers, Documents, Analysis, Reports, Audit, Settings.

Core components:
AppShell, PageHeader, Breadcrumbs, MetricCard, DataTable, FilterBar, StatusBadge,
EvidenceDrawer, ConfidenceBadge, ExceptionBanner, RuleExplanation, AIActivityPanel,
ApprovalPanel, Timeline, UploadZone, FileStatus, EmptyState, ErrorState, ConfirmDialog,
DiffViewer, ExportButton, ScenarioCard, RiskHeatmap, CostWaterfall, ScoreBreakdown, ActivityLog.

Every screen:
loading, empty, partial, success, error, denied, stale/processing where applicable.

AI display:
label AI-generated text, show evidence links, confidence and last-updated timestamp.
