# Golden Test Matrix — Supplier Onboarding & Qualification Agent

- GT-01: complete clean supplier pack
- GT-02: missing certificate
- GT-03: expired insurance
- GT-04: contradictory tax id
- GT-05: duplicate supplier entity
- GT-06: evidence correction
- GT-07: SoD approval block
- GT-08: AI extraction outage

Every golden test stores canonical input JSON, expected output JSON, expected rule/policy version and expected result hash or tolerance where mathematically appropriate.
